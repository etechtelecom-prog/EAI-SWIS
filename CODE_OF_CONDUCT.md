# Code of Conduct

EAI-SWIS is committed to a professional, respectful, and collaborative environment.

Participants must:
- communicate respectfully;
- review ideas and code without personal attacks;
- protect confidential and operational information;
- avoid discrimination and harassment;
- disclose conflicts of interest;
- use project data and software responsibly.

Serious concerns may be reported privately to etechtelecom@gmail.com.
