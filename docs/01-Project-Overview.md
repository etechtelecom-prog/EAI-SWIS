# 01. Project Overview

## Purpose

EAI-SWIS provides a modular geospatial platform for recording, visualizing, analyzing, and managing waste-related operational information.

## Intended stakeholders

- Local governments and municipalities
- Provincial organizations
- Environmental agencies
- Research institutions
- Smart-city programs
- Field inspection and collection teams
- System administrators and decision makers

## Operational scope

The platform supports incident reporting, illegal-dumping records, photographs, GPS positions, collection operations, map layers, dashboard indicators, and future decision-intelligence services.

## Product boundaries

The current alpha release is a starter platform. It is not yet a certified production system and does not by itself guarantee regulatory compliance, security certification, service availability, or accuracy of demonstration data.

## Success criteria

- Reports can be captured with valid location and operational attributes.
- Users can inspect incidents on maps and dashboards.
- Data can be retained offline and synchronized safely.
- Administrators can manage users, organizations, roles, and reference data.
- Production deployments can be audited, backed up, restored, and maintained.
