# 09. User Manual

## Standard workflow

1. Open the authorized web, desktop, or mobile client.
2. Sign in when authentication is enabled.
3. Select the operational area.
4. Create or inspect a waste report.
5. Verify map location and incident attributes.
6. Attach photographs where authorized.
7. Submit or update the operational status.
8. Review assigned work and dashboard indicators.
9. Export only data the user is authorized to access.

## Data quality

Users should confirm coordinates, date/time, category, urgency, description, and photographs before submission. Demonstration records must not be used as official operational evidence.

## Offline operation

Offline records should show synchronization status. Users must avoid duplicate submissions and should not uninstall or clear application data before synchronization is confirmed.
