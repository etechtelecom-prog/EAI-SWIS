# 14. System Maintenance

## Routine operations

Daily:
- review service health and critical errors;
- verify backup completion;
- inspect synchronization failures.

Weekly:
- review audit and security events;
- check storage and database growth;
- triage issues and dependency alerts.

Monthly:
- test a restoration;
- review user access;
- patch dependencies;
- archive records according to policy;
- validate map layers and reference data.

## Release maintenance

Every release should include a version, changelog, migration notes, security impact, rollback plan, and approved artifact checksums.
