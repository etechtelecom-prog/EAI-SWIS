# Security Policy

## Supported versions

Security updates are currently provided for the latest development branch only. EAI-SWIS is an alpha-stage project and must not yet be treated as production-certified software.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Send a private report to:

**Dr. Apichat Choomkong**  
Email: etechtelecom@gmail.com

Include:
- affected component and version;
- reproduction steps;
- potential impact;
- logs or screenshots with secrets removed;
- recommended mitigation, when available.

## Security baseline

Production deployments must implement HTTPS, secure configuration, secret management, authentication, authorization, audit logging, backups, dependency scanning, input validation, and data-retention controls.

Never commit passwords, tokens, private keys, personal records, database dumps, or operational credentials.
